# WanderLust

WanderLust is a full-stack travel and vacation rental web application where users can discover places to stay, explore listings, and plan their next trip. The project is designed to make browsing and sharing travel stays simple and intuitive.

## Features

- Browse travel and vacation rental listings
- View details, photos, location, and pricing for each stay
- Create, edit, and delete listings
- User authentication and authorization
- Leave reviews and ratings
- Upload listing images
- Responsive design for desktop and mobile

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** Passport.js
- **Image hosting:** Cloudinary

## Getting Started

1. Clone this repository.
2. Install dependencies with `npm install`.
3. Create a `.env` file and add the required environment variables.
4. Start the app with `npm start`.
5. Open the local URL shown in your terminal.

WanderLust is a learning project built to practice full-stack web development, including CRUD operations, authentication, database integration, and image uploads.
